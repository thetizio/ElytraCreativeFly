As the name says, in addition to its normal function, wearing an elytra <ins>in the chestplate armor slot</ins> grants creative fly.

By default, it is only compatible with soul elytra from deeper and darker, but you can add an item to the tag elytracreativefly/tags/item/elytra.json to make it give you creative fly when equipped in the chestplate slot.

If trinkets/curios is installed, <ins>vanilla elytra</ins> can be equipped in the <ins>trinket slot</ins> to give you creative fly.

If you <ins>installed both this mod and trinkets/curios</ins>, you do <ins>NOT need Elytra Slot</ins> mod.

Some interactions with other mods could cause creative fly to be disabled, if that happens, just re-equip the elytra.
